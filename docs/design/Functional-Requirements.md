# Functional Requirements

The system shall allow users to:

1. Register and log in securely.
2. Create, edit, and delete projects.
3. Create, assign, update, and delete tasks.
4. Manage team members.
5. Track task progress.
6. Set priorities and deadlines.
7. Search and filter projects and tasks.
8. View dashboard and reports.
9. Receive task notifications.
10. Manage user profiles.

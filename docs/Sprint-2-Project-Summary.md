# Sprint 2 - Project Summary

## Project Name
Task & Project Management System

## Problem Statement
Managing projects and tasks manually often leads to missed deadlines, poor communication, and reduced productivity.

## Objective
Develop a web and mobile application to manage projects, assign tasks, track progress, and improve team collaboration.

## Target Users
- Administrator
- Project Manager
- Team Member
- Client

## Core Modules
- User Authentication
- Dashboard
- Project Management
- Task Management
- Team Management
- Notifications
- Reports

## Included Features
- User Login & Registration
- Project Management
- Task Assignment
- Team Collaboration
- Dashboard
- Reports
- Notifications

## Excluded Features
- AI Features
- Payment Gateway
- Video Conferencing
- Third-party Integrations

## Sprint 2 Outcome
Completed project planning, requirement analysis, project scope, stakeholders, and system requirements.
